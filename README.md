# AutoInspect AI 🚗⚡

> **Intelligent Automotive Vision & Damage Estimation Suite**  
> Computer Vision Defect Detection, 360° Chassis Diagnostics, Automated Mitchell/Audatex Claims Costing, FLIR Thermal Heatmap & AI Voice Copilot.

---

## 🌟 Key Features

- 🔍 **AI Vision Surface Scanner**: Interactive defect localization with laser sweep animations, bounding box reticles, instance segmentation masks, and confidence score filtering.
- 🎙️ **AI Voice Copilot & Speech Briefing**: Native Web Speech narration of vehicle damage assessments, severity alerts, and estimated repair costs with dynamic audio equalizer waves.
- 🔥 **Multi-Spectral Thermal / Stress Heatmap**: FLIR infrared damage gradient overlay highlighting structural stress concentrations.
- 🚘 **360° Chassis & Body Shell Matrix**: Interactive top-down schematic with 12 perimeter inspection zones (Bumpers, Hood, Windshield, Doors, Quarters, Trunk).
- 💰 **Automated Claims & Repair Cost Estimator**: Itemized OEM replacement parts, paint refinishing, labor calculation, and interactive deductible slider.
- 📋 **Fleet Audit Ledger**: Searchable, filterable audit history of claims with severity tracking and status tags.
- 📸 **Custom Neural Vision Pipeline Uploader**: Drag & drop custom car photos with a simulated 4-stage YOLOv11 inference pipeline.
- 📄 **Certified Damage Appraisal PDF Report**: Formal inspection sheet with cryptographic verification seal, ready for print and insurance adjudication.

---

## 🛠️ Technology Stack

- **Frontend**: React 19, Vite 8, Vanilla CSS (Design Tokens, Glassmorphism & Cyberpunk Theme)
- **Audio Synthesizer**: Web Audio API Sound Effects (`audio.js`)
- **Speech Engine**: Web Speech Synthesis API (`VoiceCopilot.jsx`)
- **Icons & FX**: Lucide Icons, Canvas Confetti

## 🚀 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/shukla9523/AutoInspect-AI.git

# Navigate to project directory
cd AutoInspect-AI

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173` in your browser.
